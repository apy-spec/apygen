# Apygen

Apygen is the **work-in-progress** [APY specification format](https://github.com/apy-spec/apy-spec) generator.
It is designed to be fast and sound on any Python program.

## Features

- Type and exceptions inference
- Function argument inference
- Completeness inference (whether the code use dynamic features or not)
- Visibility inference (public/subclass/internal)
